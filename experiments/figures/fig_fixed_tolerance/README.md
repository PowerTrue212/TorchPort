# 固定容差失效：三张论文风格图

本目录只输出三段独立图片，每张同时提供 PNG（360 dpi）和 PDF：

- `01_fixed_tolerance`：纵轴断轴双柱图，对比 TF32 开关下超出旧容差的元素比例。上下坐标区无缝拼接，断轴只标在坐标轴上，柱体保持连续。
- `02_runtime_variation`：对数散点图，呈现稍后阶段测得的算子重复运行波动；不叠加旧容差线。
- `03_error_amplification`：直接读取小型网络实验的真实逐层增益，比较末层增益最高和最低的两个条件。

运行：

```powershell
E:\Anaconda\python.exe experiments\figures\fig_fixed_tolerance\plot.py
```

## 数据与表达边界

- 第一张使用用户提供的 `75,973 / 81,920` 和 `569 / 81,920`，固定容差为 `1e-4`。
- 第二张使用现有环境测量：矩阵乘、归一化、归一指数记录为 `0`；卷积约 `1.8e-7`；汇聚、求和约 `2e-6`。这组测量与旧固定容差实验不在同一阶段，因此图中不再画旧容差线。
- 第三张直接读取 `docs/evidence/precision_small/results.json` 中的 `gain_per_layer`。两条线分别是无归一化条件下的“过大初始化＋真实数据”和“Xavier 初始化＋随机噪声”，末层分别约为 `4.7e13` 和 `4.7e-5`。

## 视觉处理

三张图统一采用接近方形的画幅、中文衬线字体、完整黑色坐标框、向内刻度、浅色虚线网格和直接标注。图片只保留判断结论所需的文字，不使用卡片式版面。
