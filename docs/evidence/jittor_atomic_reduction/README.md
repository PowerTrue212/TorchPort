# Jittor 原子归约因果实验

这组实验回答一个窄问题：Jittor 部分 CUDA 算子的重复运行波动，是否来自并行归约中不固定的
原子累加顺序。

## 结论

在 Jittor 1.3.9.14、RTX 3080 Ti（sm_86）、CUDA 12.8、`conv_opt=1` 下，证据链已经闭合：

1. 同一个 `(1,64,176,176)` float32 输入重复执行时，内置空间求和、全局平均池化和 3×3 卷积
   均不逐位稳定。
2. 这三个算子的本机生成内核都直接包含 `atomicAdd`。
3. 显式使用 `atomicAdd` 的同定义空间求和同样波动；改为一个输出对应一个线程块、按固定二叉树
   合并后，30 次运行的输出逐位相同。
4. 三个独立进程共 90 次运行仍保持相同分界：原子路径波动，固定树和两步归约逐位一致。

因此，可以确认本实验中空间归约的运行间差异来自不固定的原子累加顺序。卷积同时具备波动和
`atomicAdd` 内核证据，但本实验没有为卷积实现固定顺序的等价内核，结论只覆盖当前形状与配置。

## 单进程结果

| 实现 | 最大运行间相对差异 | 相对 fp64 最大误差 | 30 次逐位一致 |
| --- | ---: | ---: | :---: |
| Jittor 空间求和 | 1.84e-6 | 1.29e-6 | 否 |
| Jittor 全局平均池化 | 1.93e-6 | 1.45e-6 | 否 |
| 显式原子归约 | 1.39e-6 | 9.98e-7 | 否 |
| 固定归约树 | 0 | 2.18e-7 | 是 |
| 两步求和 | 0 | 2.17e-7 | 是 |
| Jittor 3×3 卷积 | 1.82e-7 | 未计算 | 否 |

数值来自 `results.json`。三进程汇总见 `cross_process.json`。

## 文件

- `probe.py`：远端 GPU 探针；输入由固定种子生成。
- `summarize_trials.py`：汇总三个独立进程的原始输出。
- `results.json`：主运行的环境、协议与汇总指标。
- `outputs.npz`：主运行的 30 次归约输出，不保存体积很大的卷积张量。
- `trials/`：三个独立进程的结果和归约输出。
- `kernels/`：本次运行实际生成的 CUDA/C++ 内核及哈希清单。
- `stdout.log`、`stderr.log`：主运行的标准输出和编译日志。

## 边界

- 这是隔离算子因果实验，尚未把固定树替换进 CamoFormer 并重新运行正式 `verify`。
- 固定树和两步归约只在当前形状、dtype、设备和 Jittor 版本上验证。
- 不能据此断言所有 Jittor 归约或卷积都不确定；已有探针中线性层、矩阵乘、Softmax、LayerNorm、
  GELU、末维均值和双线性插值在对应测试形状上逐位稳定。
- 扩大容差、挑选最好一次结果或平均多次输出不属于修复。
